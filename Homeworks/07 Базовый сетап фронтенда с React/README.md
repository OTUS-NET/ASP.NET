# React и запросы к API

Учебное приложение на React, TypeScript и Vite. По нажатию на кнопку оно получает случайный факт о кошках с `https://catfact.ninja/fact` с помощью Axios.

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки выполните `npm run build`.

Успешный ответ отображается в зелёной карточке, а HTTP- и сетевые ошибки — в отдельном красном сообщении.
